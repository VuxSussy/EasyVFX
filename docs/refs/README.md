# VFX references

`catalog.json` lists every reference we study or use. Each entry has its link, creator, licence, tags, how close it is
to SE370's target look, and our own short notes.

- **Licence:** `cc0` art may ship (docs/cc0-library.md). Everything else is `reference`: study only. We never copy it
  into the library or the game.
- **Media stays local.** Clips, frames and images live in `.cache/refs/inbox/<local>`, untracked. This repo is public,
  so it carries only links, credits and notes.
- **Target:**
  - `anchor`: the look to aim for. The anchors are Last Flag's concepts, Daryll Española's Stylized Fire Pit and Iris
    Sebirot's Elemental Projectile Study: stylized shapes with realistic touches.
  - `close`: near that look.
  - `lesson`: a before and after that shows what separates good from great.
  - `technique`: how something is made.
  - `study`: learning only, never shipped.
- **Dissections:** a reference's dissection breaks it into beats and layers, with each layer's timing. It lives beside
  the catalogue (`dissection-*.md`) and feeds the layer library and the archetypes.
